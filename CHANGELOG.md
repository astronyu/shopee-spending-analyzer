# Changelog

## 1.0.1

- Fixed worksheet XML element ordering that caused Microsoft Excel to repair or remove worksheet contents.
- Added Shopee Taiwan (TWD) and Brazil (BRL) detection alongside the existing six markets.
- Prevented Excel export when the scan captured no orders.
- Corrected the popup version label to match the v1.0.1 manifest during repository publication.
- Added installation, privacy, accuracy and market-validation documentation, an MIT license and inspiration credits.

Malaysia was validated in the original development session. Singapore, Philippines, Indonesia, Thailand, Vietnam, Taiwan and Brazil are supported by design but have not been individually validated.

## 1.0.0

- Initial Manifest V3 extension for scanning Shopee purchase history using the current browser session.
- Local Excel export with Summary, Orders, Items and Analytics worksheets.
- Initial market detection for Malaysia, Singapore, Philippines, Indonesia, Thailand and Vietnam.
